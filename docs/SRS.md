# 1. Descripción del proyecto

Betty Tattoos es una aplicación web diseñada para digitalizar la gestión del negocio de Betty, una tatuadora independiente.

La plataforma permitirá a los clientes explorar el portafolio de trabajos realizados, solicitar tatuajes personalizados, reservar diseños Flash disponibles y realizar pagos de forma segura.

Además, Betty dispondrá de un panel administrativo desde el cual podrá gestionar clientes, reservas, diseños Flash, pagos y el contenido de la página.

- Aumentar la cantidad de clientes.

- Organizar mejor las reservas.

- Reducir la cantidad de mensajes por Instagram.

- Centralizar toda la información del negocio.

- Desarrollar una aplicación Full Stack.

- Implementar autenticación.

- Aprender Node.js.

- Implementar MongoDB.

- Integrar Stripe.

- Aprender buenas prácticas de arquitectura.
